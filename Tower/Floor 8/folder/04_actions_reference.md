# FLOOR 8: THE HUMAN VILLAGE
### Part 4 — Action Reference

Two currencies, both spent from the same 10-hour (600-minute) Production Phase clock (`01`):

- **Major Action Points (MAP), 1 MAP = 1 hour.** Anything that actually moves GP, goods, or influence.
- **Round Action Points (RAP), 1 RAP = 5 minutes.** Legwork — talking, moving, quick prep.
